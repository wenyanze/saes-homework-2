# 开发文档

## 1. 模块划分

| 文件 | 职责 |
| --- | --- |
| `saes.py` | S-AES 原语、密钥扩展、分组加解密、字节扩展、CBC、多重加密、MITM |
| `app.py` | Tkinter 图形界面；只负责输入校验、状态展示和调用核心 API |
| `saes_cli.py` | 可复现命令行实验入口 |
| `tests/test_saes.py` | 附录 D 示例、标准向量、功能和攻击测试 |
| `tests/test_gui.py` | 隐藏 Tk 窗口的 CBC 界面状态回归测试 |
| `demo.py` | 实际调用算法输出基础、ASCII、多重加密、MITM 和 CBC 演示 |
| `cross_test.py` | 调用另一组 C++ 程序，保存交叉测试数据、摘要和版本指纹 |

核心模块不依赖 GUI，因此可以在跨平台脚本、单元测试或另一种界面中复用。

算法的状态布局、轮流程和密钥扩展见[算法说明](算法说明.md)。

## 2. 多分组数据和填充

ASCII 及 CBC API 使用块大小 2 bytes 的 PKCS#7 填充。这样即使明文长度恰好是 2 的倍数，解密也能无歧义地移除填充。CBC 对每个大端 16 bit 分组执行：

```text
C_i = E_K(P_i XOR C_(i-1)), C_0 = IV
P_i = D_K(C_i) XOR C_(i-1)
```

核心 API 返回 `bytes`，GUI 和 CLI 用大写 hex 作为可复制、可跨平台的传输表示。

## 3. MITM 设计

双重加密定义为 `C=E_K2(E_K1(P))`。完整搜索的两端枚举阶段需要 `2^16 + 2^16` 次 S-AES 调用，另加匹配候选的验证开销。当前实现按顺序使用已知明密文对复核候选，遇到不匹配即停止验证该候选；每验证一对需调用两次 S-AES 加密。前向表保存 `2^16` 个 K1 及其对应的中间值，空间复杂度为 `O(2^16)`；返回的候选列表另占空间。中间相遇避免直接遍历 `2^32` 个密钥对。

由于 S-AES 仅用于教学，单个明密文对可能出现多个候选；使用更多独立明文可以过滤伪候选。

## 4. 接口调用契约

以下为核心模块 `saes` 的接口。调用不依赖 GUI；所有数值均为整数而不是 HEX 字符串。16位参数范围为 `0..65535`，不接受 `bool`。字符串输入先用 `parse_hex` 转换。公共接口遇到类型错误通常抛出 `TypeError`，数值越界或格式错误通常抛出 `ValueError`。

### 4.1 基础分组与密钥

| 接口 | 参数及约束 | 返回值 | 主要异常 |
| --- | --- | --- | --- |
| `encrypt_block(plaintext, key)` | 两个16位整数 | 16位密文整数 | 非整数或布尔值：TypeError；越界：ValueError |
| `decrypt_block(ciphertext, key)` | 两个16位整数 | 16位明文整数 | 同上；错误密钥不保证报错，会产生另一明文 |
| `expand_key(key)` | 16位初始密钥 | `(K0, K1, K2)`，三个16位轮密钥 | 类型或范围错误 |
| `encrypt_trace(plaintext, key)` | 与单分组加密相同 | `(ciphertext, trace)`；trace为`(阶段名称, 状态整数)`组成的元组 | 类型或范围错误 |
| `parse_hex(value, bits, name='value')` | HEX字符串，支持前后空白和`0x`；本项目使用16/32/48位 | 对应整数 | 非字符串：TypeError；空值、非法字符、位数超限：ValueError |
| `format_hex(value, bits=16)` | 指定宽度内的整数；本项目使用4的倍数位宽 | 补前导零的大写HEX字符串 | 类型或范围错误 |

### 4.2 字符串与字节接口

| 接口 | 参数及约束 | 返回值 | 主要异常 |
| --- | --- | --- | --- |
| `encrypt_bytes(data, key)` | `bytes`或`bytearray`，允许空数据；16位密钥 | PKCS#7填充后逐2字节独立加密的`bytes` | 非字节数据：TypeError；密钥类型或范围错误 |
| `decrypt_bytes(data, key)` | 非空、长度为2的倍数的密文字节 | 移除填充后的原始`bytes` | 未对齐、空密文或无效填充：ValueError |
| `ascii_encrypt(text, key)` | 仅含ASCII字符的`str`，允许空字符串 | 密文`bytes`，不是可直接打印的ASCII文本 | 非字符串：TypeError；非ASCII：ValueError |
| `ascii_decrypt(ciphertext, key)` | 同`decrypt_bytes`输入 | 解密及去填充后的`str` | 密文/填充无效或解密结果不是ASCII：ValueError |
| `bytes_to_display(data)` | `bytes`或`bytearray` | 可打印字符、反斜杠转义和`\xNN`组成的显示字符串 | 非字节数据：TypeError |

填充长度始终为1或2字节；偶数长度和空明文也添加完整填充块。错误密钥可能产生无效填充，但填充通过不能证明密钥正确。显示字符串仅用于阅读，程序传输和粘贴密文使用 `ciphertext.hex()` / `bytes.fromhex()`。

### 4.3 双重与三重加密

`double_encrypt(plaintext, key1, key2)` 和 `double_decrypt(ciphertext, key1, key2)` 的分组及每段密钥均为16位整数，返回16位整数。双重加密顺序为先K1后K2；解密顺序相反。

`triple_encrypt` / `triple_decrypt` 的 `key3` 默认是 `None`，`mode` 默认是 `ede`，规则如下：

| mode | 密钥要求 | 加密顺序 |
| --- | --- | --- |
| `eee` | K1/K2/K3均必填 | E(K1)→E(K2)→E(K3) |
| `ede` | K1/K2/K3均必填 | E(K1)→D(K2)→E(K3) |
| `ede2` | K1/K2必填；忽略K3 | E(K1)→D(K2)→E(K1) |

模式名不区分大小写，支持前后空白；`2-key-ede`、`2key-ede`是`ede2`的别名。非法模式或三密钥模式缺失K3抛出`ValueError`。实际使用的分组/密钥仍执行类型和范围校验。32/48位密钥在调用接口前拆成两个/三个16位整数，不直接作为单个参数传入。

### 4.4 CBC 与篡改

| 接口 | 参数及约束 | 返回值 | 主要异常 |
| --- | --- | --- | --- |
| `cbc_encrypt(plaintext, key, iv)` | 明文为`bytes`/`bytearray`，允许空；key、iv均为16位整数 | 自动PKCS#7填充的密文`bytes` | 数据/整数类型错误；key或iv越界 |
| `cbc_decrypt(ciphertext, key, iv)` | 非空且长度为2倍数的字节数据；相同key、iv | 去填充后的明文`bytes` | 空或未对齐密文、无效填充：ValueError |
| `tamper_ciphertext(ciphertext, block_index, xor_mask)` | 对齐密文；索引从0起且小于分组数；16位掩码 | 修改一个分组后的新`bytes`，不修改原数据 | 索引非整数/布尔值：TypeError；索引越界、未对齐、掩码越界：ValueError |

CBC API 不自动生成或封装IV。调用方可用 `secrets.randbits(16)` 生成，将IV与密文一同保存或共享。掩码为0不会改变密文。篡改最后两组可能破坏末尾填充；此时解密报错而不返回部分明文。

### 4.5 中间相遇攻击

```python
meet_in_the_middle(
    pairs,
    *,
    progress=None,
    max_results=None,
    cancelled=None,
) -> list[tuple[int, int]]
```

| 参数 | 类型与语义 |
| --- | --- |
| `pairs` | 非空可迭代对象；每项为`(plaintext, ciphertext)`，均为16位整数，且应由相同双重密钥产生 |
| `progress` | 可选回调`callback(stage, current, total)`；stage为`forward`/`backward`，total为65536，current为该阶段已枚举数量；完整阶段结束会报告65536 |
| `max_results` | `None`表示不限制；否则必须为正整数且不能是bool。达到上限即返回，结果不保证穷尽 |
| `cancelled` | 可选无参回调，返回True时抛出`concurrent.futures.CancelledError`；不返回部分候选 |

返回全部已发现且满足所有输入对的`(K1, K2)`列表。无匹配返回`[]`；多个匹配表示信息不足，不能把首项直接视为真实密钥。空输入对、数值越界或非正上限抛出`ValueError`，整数类型错误或非法上限类型抛出`TypeError`；输入项不能解包为两个值时也会报错。

回调在调用搜索的同一线程执行，回调异常向上传播。GUI 应在后台线程执行搜索并通过队列传递进度，禁止在回调中直接更新 Tk 控件。

## 5. 可运行调用示例

以下示例均从项目目录运行，或保证项目目录在Python模块搜索路径中。

### 基础加解密及轮密钥

```python
from saes import encrypt_block, decrypt_block, expand_key, format_hex

ciphertext = encrypt_block(0xD728, 0x4AF5)
assert ciphertext == 0x24EC
assert decrypt_block(ciphertext, 0x4AF5) == 0xD728
assert expand_key(0x2D55) == (0x2D55, 0xBCE9, 0xA34A)
print(format_hex(ciphertext))  # 24EC
```

### ASCII、双重与三重加密

```python
from saes import (
    ascii_encrypt, ascii_decrypt, double_encrypt, double_decrypt,
    triple_encrypt, triple_decrypt,
)

encrypted = ascii_encrypt("S-AES demo", 0x4AF5)
assert ascii_decrypt(encrypted, 0x4AF5) == "S-AES demo"
ciphertext = double_encrypt(0x1234, 0x1A2B, 0x3C4D)
assert ciphertext == 0xF04D
assert double_decrypt(ciphertext, 0x1A2B, 0x3C4D) == 0x1234
ciphertext = triple_encrypt(0x1234, 0x1A2B, 0x3C4D, mode="ede2")
assert ciphertext == 0x3044
assert triple_decrypt(ciphertext, 0x1A2B, 0x3C4D, mode="ede2") == 0x1234
```

### CBC 和篡改对比

```python
from saes import cbc_encrypt, cbc_decrypt, tamper_ciphertext

key, iv = 0x4AF5, 0x1234  # 固定IV仅用于复现本例
plaintext = b"CBC tamper demonstration"
ciphertext = cbc_encrypt(plaintext, key, iv)
assert cbc_decrypt(ciphertext, key, iv) == plaintext
modified = tamper_ciphertext(ciphertext, 0, 0x0001)
assert cbc_decrypt(modified, key, iv) == b"SFC!tamper demonstration"
```

### MITM 密钥恢复

```python
from saes import meet_in_the_middle

pairs = [(0x1234, 0xF04D), (0xBEEF, 0x62E6), (0xCAFE, 0x8ACE)]
candidates = meet_in_the_middle(pairs)
assert candidates == [(0x1A2B, 0x3C4D)]
print([(f"{k1:04X}", f"{k2:04X}") for k1, k2 in candidates])
```

### 输入错误处理

```python
from saes import decrypt_bytes

try:
    decrypt_bytes(b"\x00", 0x4AF5)  # 密文只有1字节，未按2字节对齐
except ValueError as error:
    print(error)
else:
    raise AssertionError("未拒绝未对齐密文")
```

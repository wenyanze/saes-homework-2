## 2. S-AES 标准流程

S-AES 的输入是 16 bit 分组和 16 bit 密钥。密钥扩展得到 `K0,K1,K2` 三个 16 bit 轮密钥：

```text
K0 = w0 || w1
K1 = w2 || w3
K2 = w4 || w5
```

加密流程：

```text
S0 = P XOR K0
S1 = MixColumn(ShiftRow(SubNib(S0))) XOR K1
C  = ShiftRow(SubNib(S1)) XOR K2
```

解密按逆序执行：

```text
S1 = InvSubNib(InvShiftRow(C XOR K2))
S0 = InvSubNib(InvShiftRow(InvMixColumn(S1 XOR K1)))
P  = S0 XOR K0
```

## 3. 附录 D 算例复核

附录 D 给出的密钥 `2D55` 扩展为：

```text
K0 = 2D55
K1 = BCE9
K2 = A34A
```

附录 D 的转换算例：

```text
SubNib(8A1C)       = 604C
ShiftRow(604C)     = 6C40
MixColumn(6C40)    = 3743
InvMixColumn(3743) = 6C40
```

这些值已经作为自动化测试固定下来，不依赖运行时重新计算期望值。

## 4. 跨程序测试向量

以下向量全部使用 4 位大写 hex 输出：

| 场景 | 输入 | 结果 |
| --- | --- | --- |
| 基础加密 | `P=D728, K=4AF5` | `C=24EC` |
| 密钥扩展 | `K=2D55` | `K0=2D55, K1=BCE9, K2=A34A` |
| 双重加密 | `P=1234, K1=1A2B, K2=3C4D` | `C=F04D` |
| 三重 EEE | `P=1234, K1=1A2B, K2=3C4D, K3=5E6F` | `C=6C0F` |
| 三重 EDE | `P=1234, K1=1A2B, K2=3C4D, K3=5E6F` | `C=5284` |
| 两密钥 EDE2 | `P=1234, K1=1A2B, K2=3C4D` | `C=3044` |

基础分组需统一状态布局、S盒、有限域、轮流程与密钥扩展；多重加密还需统一模式及密钥顺序，多分组还需统一填充和 IV。已完成基础 1006 组、双重 100 组、三重 EEE 100 组实际交叉验证，见 [报告](tests/cross-test/report.md)。EDE/EDE2 为本项目本地测试结果，未与对方交叉验证。

## 5. 安全边界

S-AES 的设计目标是教学而非实际保密。它的分组和密钥空间都很小，MITM 攻击可以在普通计算机上完成。CBC 只提供保密性，不提供完整性；本项目主动展示篡改后明文变化，说明实际系统必须叠加 MAC 或使用 AEAD。
